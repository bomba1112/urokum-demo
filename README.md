# Урокум — демо

Кликабельный прототип приложения «Урокум» для учителя начальных классов (Азербайджан, русский сектор).

- Один файл `index.html`: без сервера, без регистрации, работает офлайн.
- Все данные — пример (демо). Тексты учебников не используются: задания составлены заново,
  у тем указаны только номера страниц учебника.

Открыть: https://bomba1112.github.io/urokum-demo/
